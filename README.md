# AlterArena

A cross-character PvP progression tracker for World of Warcraft (Retail).

## What it does

- **Roster Overview** — every character you play, side by side, with current ratings, season peaks, tier name, W/L record, and currencies (Conquest / Honor / Bloody Tokens).
- **Match History** — a detailed ledger of every rated match you've played, filterable by bracket, result, map, date, and season.
- **Queue Timer** — a movable HUD widget showing wait time and expected duration while you queue.
- **Currency Alerts** — a toast warning when Honor or Bloody Tokens approach their caps so you never waste gains.

## Slash commands

- `/alterarena` — open the main window
- `/aa debug` — toggle verbose logging
- `/aa alerttest` — preview the currency alert
- `/aa reset` — wipe and rebuild the rating cache

## Compatibility

Retail only. Tested on 12.1.0.
